ChemInventory

Chemical inventory software that fits how each lab works. It gives a lab one record of what it holds, where it is, and who changed it.

  • Tracks chemicals, locations, orders and batch documents.
  • Keeps a change history with the user and the time.
  • Gives each person a role: admin, manager or chemist.

The demo uses sample data. Changes reset when you refresh.

Bench Bridge

A demo of how older lab instruments can feed a laboratory information management system (LIMS) and a controlled-substance ledger. It reads each instrument's own output, applies the lab's rules and delivers the records.

  • Instruments in the demo: Analytical balance, HPLC system, GC system, GC-MS, pH meter, Karl Fischer titrator.
  • Each run shows the raw capture, the parsed readings, the rules and the delivered records.
  • Concept drawings show the tap hardware that would connect to each instrument.

The demo runs in your browser with sample data and a mock LIMS. No real instrument or LIMS is connected.
